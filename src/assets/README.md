# Images Directory

Place your three photos here with the following naming convention:

- `photo1.jpg` (or `.jpeg`, `.png`, `.webp`, `.gif`)
- `photo2.jpg` (or `.jpeg`, `.png`, `.webp`, `.gif`)
- `photo3.jpg` (or `.jpeg`, `.png`, `.webp`, `.gif`)

The project will automatically detect the file extensions and load them in the correct order.

Example:
- `photo1.jpg`
- `photo2.png`
- `photo3.webp`

All three images will display in the "Our Memories" gallery section with the captions:
1. "Us ❤️"
2. "My favorite memories 🥹"
3. "My favorite person ❤️"
