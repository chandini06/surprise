# Pixel Perfect Memories

A standalone Vite + React app with a romantic memory-gallery experience and local image assets.

## Development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

The app uses local photo imports from `src/assets/photo1.jpg`, `src/assets/photo2.jpg`, and `src/assets/photo3.jpg` to keep the design working without external or Lovable-hosted asset URLs.
